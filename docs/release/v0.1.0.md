AGY Switcher is a macOS menu bar app for switching Google accounts in Antigravity and `agy`, checking remaining quotas, and tracking local `agy` usage.

## What you can do

- **Manage and switch accounts.** Add personal Google accounts with Antigravity access through your browser, then switch from **Accounts** or the menu bar. AGY Switcher attempts to restart Antigravity if it is running. Restart `agy` to start a session with the selected account.
- **Check remaining quotas.** See the active account, remaining quota for each model group, and when each quota resets. Refresh manually or set an interval for refreshing stale quotas when you open **Accounts** or the menu bar panel.
- **Review local usage.** Open **Usage** for 7- or 30-day input and output token totals, daily trends, and estimated costs in USD. Turn on **Enable Account Attribution** to group newly started interactive `agy` sessions by sign-in email.
- **Set up menu bar access.** Choose Simplified Chinese or English, set the appearance, hide the Dock icon, or launch into the menu bar at login.
- **Get app updates.** Use **Settings → Software update** to check for newer stable releases and read bilingual release notes. Access to updates for a private repository requires a GitHub token with read-only access to the repository's contents.

## Install on macOS

Requires **macOS 26 or later**. Download `AGY-Switcher-v0.1.0-macOS-universal.dmg` from the release assets, open it, and drag **AGY Switcher** into Applications. The signed and notarized installer supports Apple Silicon and Intel Macs.
