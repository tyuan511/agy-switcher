AGY Switcher v0.2.4 fixes a code-signing mismatch that prevented v0.2.3 from launching on macOS.

## Fixes & refinements

- **Fixed app launch failure in v0.2.3.** Updated the release signing certificate to match the embedded Developer ID provisioning profile and added a build-time verification check so signed builds launch cleanly with Data Protection Keychain enabled.
