AGY Switcher v0.2.0 makes it easier to move accounts between Macs, redesigns the usage view around richer local data, and ships separate installers for Apple Silicon and Intel Macs.

## New features

- **Back up and move accounts.** In **Settings → Export & Import**, export every account with its sign-in credentials into a passphrase-encrypted `.agyaccounts` file, then import it on another Mac. Accounts that already exist remain unchanged.
- **Usage now covers Antigravity sessions.** The **Usage** page reads local Antigravity and `agy` session records on this Mac and aggregates input and output tokens by day. A new **Cache Hit Rate** shows the share of input tokens read from cache, and the daily trend chart supports hovering to preview values and clicking to pin a day for step-by-step comparison.
- **Fewer keychain interruptions.** Account credentials now live in an encrypted local vault whose master key stays in the macOS keychain; existing keychain items migrate automatically on first use. When quota refresh needs keychain permission, the app shows an in-app **Authorize** prompt instead of leaving repeated system dialogs to background refreshes.

## Refinements

- The menu bar panel presents each account as a card and highlights the active account.
- **Software update** shows the current version, marks the **Settings** entry in the sidebar when an update is available, and makes **Download and Restart** the primary action.
- Hiding the Dock icon no longer needs a separate setting; the app stays in the menu bar automatically when you close the window.

## Breaking changes

- **Usage is no longer broken down by account.** The account attribution feature was removed, and usage is aggregated per Mac. Sessions recorded before this version are still counted.
- **Installers are per chip.** Release assets are now `AGY-Switcher-v*-macOS-arm64.dmg` for Apple Silicon and `-macOS-amd64.dmg` for Intel; in-app updates pick the matching installer automatically. When upgrading from v0.1.0 (universal installer), download the matching DMG and install it manually once.
- **The GitHub token setting was removed.** The repository is public now, so update checks work without a personal access token.

## Install on macOS

Requires **macOS 26 or later**. Download the installer for your Mac from the release assets, open it, and drag **AGY Switcher** into Applications.

| Chip | Installer |
| --- | --- |
| Apple Silicon | `AGY-Switcher-v0.2.0-macOS-arm64.dmg` |
| Intel | `AGY-Switcher-v0.2.0-macOS-amd64.dmg` |
