AGY Switcher v0.2.2 eliminates macOS Keychain password prompts and improves account switching reliability.

## Fixes & refinements

- **No more keychain password prompts.** Signed builds now store the local vault master key in the macOS Data Protection Keychain (migrating existing keys automatically) and access the shared Antigravity credential without triggering legacy login keychain permission dialogs.
- **More reliable account switching.** When switching accounts while Antigravity is running, AGY Switcher now closes Antigravity and its background processes before writing the new credentials—updating the shared keychain before local files—and relaunches it afterward so active watchers cannot overwrite the switched account.
