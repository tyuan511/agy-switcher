AGY Switcher v0.2.1 refines quota row layout and fixes main window activation from the menu bar.

## Fixes & refinements

- **Compact quota reset times.** Grouped quota windows (such as weekly and 5-hour quotas) now show their reset countdown on the same line as the window label, while single-model entries keep their two-line layout.
- **Activate window on open.** Clicking **Open Window** from the menu bar popover or right-click menu now reliably activates the app, restores the main window if minimized, and brings it to the front.
