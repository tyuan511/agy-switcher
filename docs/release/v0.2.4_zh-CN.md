AGY Switcher v0.2.4 修复了导致 v0.2.3 在 macOS 上无法启动的签名证书不匹配问题。

## 修复与改进

- **修复 v0.2.3 无法打开的问题。** 更新发布签名证书以匹配内嵌的 Developer ID Provisioning Profile，并在构建脚本中加入签名证书与 Profile 的匹配校验，确保启用 Data Protection Keychain 的签名版本能够正常启动。
