AGY Switcher v0.2.0 让账号在不同 Mac 之间迁移更轻松，重做了「用量」页面，并为 Apple Silicon 和 Intel Mac 提供独立的安装包。

## 新功能

- **备份并迁移账号。** 在「设置 → 导出与导入」中，把全部账号及其登录凭据导出为密码加密的 `.agyaccounts` 备份文件，再到另一台 Mac 上导入。已存在的账号保持不变。
- **用量统计覆盖 Antigravity 会话。** 「用量」页面读取本机 Antigravity 与 `agy` 的会话记录，按天汇总输入和输出 Token。新增「缓存命中率」，展示从缓存读取的输入 Token 占比；每日趋势图支持悬停预览数值、点击固定某一天逐日对比。
- **更少钥匙串打扰。** 账号凭据改为保存在本地加密保管库，主密钥仍存于 macOS 钥匙串；旧钥匙串条目会在首次使用时自动迁移。自动刷新配额需要钥匙串授权时，应用会在界面内给出「授权」提示，不再让后台刷新反复弹出系统窗口。

## 体验改进

- 菜单栏弹窗改为卡片式布局，突出当前账号。
- 「软件更新」会显示当前版本；有更新时侧边栏「设置」会标出圆点，「下载并重启」成为主要操作。
- 隐藏 Dock 图标不再需要单独设置：关闭窗口后应用自动驻留菜单栏。

## 重要变化

- **用量不再按账号拆分。** 账号关联功能已移除，用量按本机汇总统计，此前记录的会话仍会计入。
- **安装包按芯片区分。** 发布附件分为 Apple Silicon 的 `AGY-Switcher-v*-macOS-arm64.dmg` 与 Intel 的 `-macOS-amd64.dmg`，应用内更新会自动选择匹配当前芯片的安装包。从 v0.1.0（通用安装包）升级时，请下载对应的 DMG 手动安装一次。
- **移除 GitHub 令牌设置。** 仓库已公开，检查更新不再需要个人访问令牌。

## 安装

需要 **macOS 26 或更新版本**。按芯片从发布附件下载安装包，打开后将 **AGY Switcher** 拖到「应用程序」。

| 芯片 | 安装包 |
| --- | --- |
| Apple Silicon | `AGY-Switcher-v0.2.0-macOS-arm64.dmg` |
| Intel | `AGY-Switcher-v0.2.0-macOS-amd64.dmg` |
