AGY Switcher 是一款 macOS 菜单栏应用，可以切换 Antigravity 和 `agy` 的 Google 账号、查看剩余配额，并统计本机 `agy` 用量。

## 首版功能

- **管理和切换账号。** 在浏览器中授权已开通 Antigravity 的个人 Google 账号，然后从「账号管理」或菜单栏切换。如果 Antigravity 正在运行，应用会尝试重启它。重新启动 `agy` 后，新会话会使用选中的账号。
- **查看剩余配额。** 查看当前账号、各模型组的剩余额度和重置时间。可以手动刷新，也可以设置间隔，在打开「账号管理」或菜单栏弹窗时刷新已超过该间隔的配额。
- **统计本机用量。** 在「用量」查看近 7 天或 30 天的输入和输出 Token、每日趋势和美元估值。选择「启用账号关联」，即可按登录邮箱统计新启动的交互式 `agy` 会话。
- **设置菜单栏访问方式。** 可切换简体中文和英文、调整外观、隐藏 Dock 图标，或让应用在登录 macOS 时启动并驻留菜单栏。
- **检查应用更新。** 通过「设置 → 软件更新」检查较新的稳定版本并查看双语发布说明。私有仓库的更新需要配置对此仓库内容具有只读权限的 GitHub 令牌。

## 安装

需要 **macOS 26 或更新版本**。从发布附件下载 `AGY-Switcher-v0.1.0-macOS-universal.dmg`，打开后将 **AGY Switcher** 拖到「应用程序」。安装包已签名并经 Apple 公证，支持 Apple Silicon 和 Intel Mac。
