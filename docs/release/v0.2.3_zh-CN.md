AGY Switcher v0.2.3 消除了 macOS 钥匙串密码弹窗，并提升了账号切换的稳定性。

## 修复与改进

- **消除钥匙串密码弹窗。** 签名版本现已启用 macOS Data Protection Keychain 存储本地凭据库主密钥（自动迁移已有密钥），并以与 Antigravity 及 `agy` 一致的方式读写共享凭据，不再触发旧版登录钥匙串权限弹窗。
- **提升账号切换可靠性。** 在 Antigravity 运行时切换账号，现在会先退出 Antigravity 及其后台进程，再按「先共享钥匙串、后本地文件」的顺序写入新凭据并重新启动应用，避免运行中的文件监听或退出回写覆盖刚切换的账号。
